# SovSwift Kenya – Digital Sovereignty & Foreign Policy

Official website for **SovSwift** – a project of the Democracy for the Citizens Party (DCP) reimagining Kenya's foreign policy for the 4th Industrial Revolution.

## Live Demo
[https://sovswift-kenya.onrender.com](https://sovswift-kenya.onrender.com)

## Features
- Responsive design (mobile-first)
- Dark mode toggle with persistence  
- Countdown to 2027 elections
- White Paper download section
- Contact form (powered by Formspree)
- Accessible and SEO-friendly

## Built With
- HTML5, CSS3, JavaScript
- Font Awesome icons
- Inter & Lora fonts (Google Fonts)

## Deployment
Deployed on Render as a static site.
