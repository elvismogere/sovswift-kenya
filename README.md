# SovSwift – DCP Foreign Policy Vision for Kenya

**SovSwift** (Sovereignty + Swift) is a comprehensive framework developed by the **Democracy for the Citizens Party (DCP)** to reimagine Kenya's foreign policy for the 4th Industrial Revolution. This project champions citizen-centric diplomacy, digital sovereignty, economic justice, cyber resilience, and global leadership – grounded in Kenya's Constitution and the party's motto: **"JUSTICE, UNITY AND PROGRESS"**.

## Live Demo

[https://sovswift-kenya.onrender.com](https://sovswift-kenya.onrender.com)

## Features

- **Dynamic Content Management** – Admin dashboard to publish blog posts and view contact messages.
- **Dark/Light Mode** – Toggle in the footer, remembers user preference.
- **Countdown Timer** – Shows days until the 2027 General Elections.
- **Contact Form** – Messages stored in a PostgreSQL database.
- **Responsive Design** – Works on mobile, tablet, and desktop.
- **Secure Admin Panel** – Password-protected.

## Technology Stack

- **Backend**: Flask (Python)
- **Database**: PostgreSQL (via Render) or SQLite (local)
- **Frontend**: HTML5, CSS3, JavaScript
- **Fonts**: Inter & Lora (Google Fonts)
- **Icons**: Font Awesome
- **Deployment**: Render
